# متطلبات الاتصال الآمن (HTTPS) للكاميرا

## لماذا يتطلب تشغيل الكاميرا اتصالاً آمناً (HTTPS)؟
تفرض متصفحات الويب قيوداً أمنية صارمة على واجهة برمجة التطبيقات `navigator.mediaDevices.getUserMedia`، حيث لا تسمح للجهود أو التطبيقات بالوصول إلى كاميرا الأجهزة إلا عبر سياقات آمنة (`Secure Contexts`). يُعتبر `localhost` و`127.0.0.1` سياقين آمنين استثناءً، بينما أي عنوان شبكة محلي آخر (مثل `http://192.168.x.x`) عبر بروتوكول HTTP العادي سيتسبب في حظر الكاميرا من قِبل المتصفح.

---

## 1. التطوير المحلي على الجهاز المضيف (Dev Machine)
عند اختبار النظام واجهة الماسح على نفس جهاز المطور، يُعتبر استخدام `http://localhost:5173` آمناً ومتاحاً بشكل مباشر دون إعدادات إضافية.

---

## 2. التطوير المحلي واختبار الهاتف المحلي (على نفس شبكة الـ WiFi)
لاختبار كاميرا الهاتف عبر شبكة الواي فاي المحلية دون أخطاء أمنية:
1. شغّل خادم التطوير باستخدام HTTPS عبر `basicSsl` (مضمّن في `npm run dev` و`npm run dev:https`):
   ```bash
   npm run dev:https
   ```
2. افتح الرابط الناتج في متصفح الهاتف على الشبكة المحلية (مثلاً: `https://<your-dev-machine-ip>:5173`).
3. عند ظهور تحذير شهادة الأمان الذاتية في المتصفح، قم بتجاوزه وقبول المتابعة (Proceed / Advanced -> Accept Certificate).

**ملاحظة هامة:** في Docker، تُقدَّم الواجهة عبر nginx على HTTP فقط (`5173:80`). لذا لن تعمل الكاميرا على الهاتف عبر عنوان IP الشبكة المحلية. لاختبار الهاتف استخدم `npm run dev` أو `npm run dev:https` (HTTPS عبر basic-ssl) أو ngrok.

**VITE_API_URL:** في التطوير، أبقِ `VITE_API_URL` **فارغاً** حتى تمرّ الطلبات عبر Vite proxy (نفس الأصل). إذا وجّهته إلى `http://<ip>:8000` بينما الصفحة `https://`، سيحظر المتصفح الطلب كمحتوى مختلط (mixed content) ويرفضه CORS.

## 3. بيئة الإنتاج (Production)
يجب دائماً نشر التطبيق في بيئة الإنتاج خلف خادم ويب مدعوم بشهادة SSL صالحة وموثوقة (مثل Nginx مع Let's Encrypt أو شهادة موثوقة من مزود معتمد). بدون HTTPS لن تعمل الكاميرا على أي هاتف.

---

## 4. بديل سريع للتجريبي (Ngrok)
كبديل سريع لتجربة الكاميرا على أي هاتف دون الحاجة لإعدادات شبكة الواي فاي أو شهادات SSL محلية:
```bash
ngrok http 5173
```
سيوفر Ngrok رابطاً آمنًا عاماً بصيغة `https://*.ngrok-free.app` يعمل بسلاسة على أي هاتف محلياً وخارجياً.
